# 玑衡 · A股量化资讯工作台

一个聚焦 A 股题材催化与事件研究的量化资讯工作台。项目提供每日题材简报、事件流、产业链关系图谱和复盘视图，并支持**中英双语**切换、**白天/黑夜**主题。

> 当前公开版本使用页面内置的拟真示例数据进行产品演示，不代表实时行情或真实投资表现。代码中保留了公开行情/快讯接口接入逻辑；第三方接口的可用性、跨域策略和数据授权情况会影响实际运行效果。

## 本地运行

```bash
./start.sh          # 默认 8000 端口，自动打开浏览器
./start.sh 9000     # 指定端口
```

或手动：`python3 -m http.server 8000` 后访问 <http://localhost:8000>。

## 部署到 GitHub Pages

页面是**单文件、零依赖、纯静态**，直接托管即可。

1. 在 GitHub 新建一个公开仓库（例如 `jiheng-quant-workbench`）。
2. 将本目录中的 `index.html`、`README.md` 和 `start.sh` 上传到仓库根目录。
3. 在仓库 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`、目录选 `/(root)`。
4. 等待 GitHub Pages 完成部署，访问 `https://<你的用户名>.github.io/<仓库名>/`。

也可以在本目录执行以下命令，通过 Git 推送：

```bash
git init
git add index.html README.md start.sh
git commit -m "Add Jiheng quant information workbench"
git branch -M main
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

随后按上面的步骤在仓库设置中开启 Pages。

## 功能

- **每日题材简报**：根据内置演示数据生成题材强弱摘要；代码包含行情接口接入逻辑
- **事件流**：内置事件样例与东方财富 7x24 快讯接口接入逻辑，英文可通过机器翻译显示
- **题材产业链图谱**：力导向交互图谱，悬停/点击/拖拽/缩放
- **复盘**：历史判断 vs 次日行情
- **中英双语**：右上角「中 / EN」切换，自动跟随系统语言
- **白天/黑夜**：主题切换，记忆偏好
